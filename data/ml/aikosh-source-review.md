# AIKosh source review

Reviewed 2026-10-13 after the project owner identified an omission in the initial source search. AIKosh must be included in the Indian government/public-data discovery checklist. This is a targeted catalogue review, not an exhaustive audit or a download receipt. Indexed descriptions were accessible; direct page extraction returned no readable content for several JavaScript-rendered listings. Recheck current downloadable files and terms before ingestion.

| Catalogue candidate | Relevance to GreenChain | Terms/access and next check |
|---|---|---|
| [ICAR Crop Disease and Insect-pest Image Dataset for Rice and Maize](https://aikosh.indiaai.gov.in/home/datasets/details/crop_disease_and_insect_pest_image_dataset_for_rice_and_maize.html) | Expert-annotated field imagery; candidate for crop-health evidence models and image-pipeline evaluation | Indexed listing specifies ICAR Data Use License and a 925.91 MB version. Review the actual licence, acquisition sites, scene-level grouping, class counts and download access. India coverage alone does not prove West Bengal representation |
| [BhashaBench-Krishi](https://aikosh.indiaai.gov.in/home/datasets/details/bhashabench_krishi.html) | Agricultural knowledge/advisory evaluation, separate from tabular/gas models | Indexed catalogue lists CC BY 4.0 and a Hugging Face redirect. Keep benchmark evaluation separate from training; inspect the original repository and languages/context tags |
| [Land Use Land Cover (2005–2024)](https://aikosh.indiaai.gov.in/home/datasets/details/land_use_land_cover_2005_2024.html) | Contextual agricultural-land/landscape inputs, subject to geospatial validation | Audit spatial coverage, licence, resolution and provenance. Indexed title and description differ on the covered years; resolve this before using time-aligned features. Generated map classes are not independently measured SOC-change labels |
| [Per Drop More Crop dataset](https://aikosh.indiaai.gov.in/home/datasets/details/pdmc_dataset.html) | Potential irrigation-adoption/coverage context | Indexed listing says Restricted and licence NA. Treat as a lead until authorised access and permitted use are established; do not infer beneficiary data are open |

No files from these candidates have been downloaded in this review. Disease labels, knowledge questions, landscape classes and irrigation-administration records serve different targets; none should be relabelled as soil-stock change or proof of carbon additionality.

Corrected discovery order for additional collection: AIKosh/AgriKosh and underlying government/ICAR sources → relevant West Bengal/state sources → original research repositories and supplemental data. Search broadly across these sources, then select by target/label fit, location, time, permissions and independence. Preserve already acquired study datasets as complementary sources rather than assuming one catalogue replaces every scientific measurement source.
